# GameSession Persistence Analysis

## 🎯 **GameSession Aggregate Data Structure**

Based on the GameSession aggregate, here's what needs to be persisted:

### **Core GameSession Properties:**
- `Id` (Guid) - Primary key
- `Name` (string) - Session name  
- `Dimensions` (BoardDimensions) - Width/Height value object
- `CurrentGeneration` (int) - Current generation number
- `Status` (SessionStatus enum) - Active/Paused/Completed/Archived
- `CreatedAt` (DateTime) - Creation timestamp
- `LastModified` (DateTime) - Last modification timestamp
- `CreatedBy` (string) - Creator identifier

### **Complex Properties:**
- `_currentBoard` (Board) - Current board state
- `_snapshots` (List<SessionSnapshot>) - Session snapshots collection
- `_settings` (SessionSettings) - Session configuration

## 📋 **Required Database Changes**

### **Tables to Add:**
1. **GameSessions** - Core session data
2. **SessionSnapshots** - Session-specific snapshots (or extend Snapshots table)

### **Table Relationships:**
```sql
GameSessions (1) → (*) SessionSnapshots
GameSessions (1) → (1) Boards (current board state)
GameSessions (1) → (*) Snapshots (current board snapshots)
```

### **Schema Changes:**
```sql
-- New table
CREATE TABLE GameSessions (
    Id UNIQUEIDENTIFIER PRIMARY KEY,
    Name NVARCHAR(100) NOT NULL,
    Width INT NOT NULL,
    Height INT NOT NULL,
    CurrentGeneration INT NOT NULL DEFAULT 0,
    Status NVARCHAR(20) NOT NULL DEFAULT 'Active',
    CreatedAt DATETIME2 NOT NULL,
    LastModified DATETIME2 NOT NULL,
    CreatedBy NVARCHAR(100) NOT NULL,
    -- Settings
    AutoSnapshotEnabled BIT NOT NULL DEFAULT 1,
    AutoSnapshotInterval INT NOT NULL DEFAULT 10,
    MaxSnapshots INT NOT NULL DEFAULT 50,
    SessionTimeoutMs BIGINT NOT NULL,
    AllowConcurrentAccess BIT NOT NULL DEFAULT 0,
    -- Board reference
    CurrentBoardId NVARCHAR(32) NULL
);

-- Either extend existing Snapshots table:
ALTER TABLE Snapshots ADD Description NVARCHAR(500) NULL;
ALTER TABLE Snapshots ADD CreatedAt DATETIME2 NULL;
ALTER TABLE Snapshots ADD IsAutoGenerated BIT NOT NULL DEFAULT 0;
ALTER TABLE Snapshots ADD EntityType NVARCHAR(20) NOT NULL DEFAULT 'Board';

-- OR create new SessionSnapshots table:
CREATE TABLE SessionSnapshots (
    Id UNIQUEIDENTIFIER PRIMARY KEY,
    SessionId UNIQUEIDENTIFIER NOT NULL REFERENCES GameSessions(Id),
    Generation INT NOT NULL,
    BoardData VARBINARY(MAX) NOT NULL,
    Description NVARCHAR(500) NULL,
    CreatedAt DATETIME2 NOT NULL,
    IsAutoGenerated BIT NOT NULL DEFAULT 0
);
```

## 🎯 **Final Recommendation**

**Use a hybrid approach:**

1. ✅ **Reuse BoardEntity/SnapshotEntity** for current board state
2. ✅ **Create GameSessionEntity** for core session data  
3. ✅ **Extend SnapshotEntity** with optional fields for session snapshots
4. ✅ **Use existing BoardSerializationService** for consistency

This approach **maximizes reuse** while providing **clean separation** and **maintaining compatibility** with existing Board persistence patterns.
